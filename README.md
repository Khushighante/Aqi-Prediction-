# Data-science-project-
AQI prediction 
Overview
Air pollution is a major global concern. This project uses historical air quality data to build a predictive model for AQI. It can help in proactive environmental decisions and public health monitoring.
Goal: Predict AQI level (Good, Moderate, Unhealthy, etc.) using pollutants like PM2.5, PM10, NO₂, CO, SO₂, O₃.
Used :- Pycharm,Excel and Python tools
+ *Language:** Python
- **Libraries:** pandas, scikit-learn, matplotlib, seaborn
- **Model:** Random Forest, Decision Tree, Linear Regression (choose based on performance)
- **Dataset:** [city_day.csv] from Kaggle
1. Clone the repository
git clone https://github.com/yourusername/aqi-prediction-ml.git
cd aqi-prediction-ml
2. Install dependencies
pip install -r requirements.txt
3. Run the model
python aqi_predictor.py
4. Optional: Visualize data
   python visualize.py
